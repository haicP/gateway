Use this page to override gateway config values at process start.

## Load Order

1. Built-in defaults.
2. `ongoingai.yaml` when present.
3. Supported environment variables.

Empty environment variable values are ignored.

## Supported Variables

| Variable | Type | Overrides |
| --- | --- | --- |
| `ONGOINGAI_HOST` | string | `server.host` |
| `ONGOINGAI_PORT` | int | `server.port` |
| `ONGOINGAI_STORAGE_DRIVER` | string | `storage.driver` |
| `ONGOINGAI_STORAGE_PATH` | string | `storage.path` |
| `ONGOINGAI_STORAGE_DSN` | string | `storage.dsn` |
| `ONGOINGAI_LOG_DIR` | string | `logging.dir` |
| `ONGOINGAI_LOG_STDOUT` | bool | `logging.stdout` |
| `ONGOINGAI_LLM_UPSTREAM` | string | `providers.llm.upstream` |
| `ONGOINGAI_CAPTURE_BODIES` | bool | `tracing.capture_bodies` |
| `ONGOINGAI_BODY_MAX_SIZE` | int | `tracing.body_max_size` |
| `ONGOINGAI_TRACE_RETENTION_DAYS` | int | `tracing.retention.days` |
| `ONGOINGAI_TRACE_CLEANUP_ENABLED` | bool | `tracing.retention.cleanup_enabled` |
| `ONGOINGAI_TRACE_CLEANUP_DAILY_AT` | string `HH:MM` | `tracing.retention.cleanup_daily_at` |
| `ONGOINGAI_TRACE_CLEANUP_TIMEZONE` | string | `tracing.retention.cleanup_timezone` |
| `ONGOINGAI_BACKUP_REQUEST_DETAILS_ENABLED` | bool | `backup.request_details.enabled` |
| `ONGOINGAI_BACKUP_REQUEST_DETAILS_TIMEZONE` | string | `backup.request_details.timezone` |
| `ONGOINGAI_BACKUP_REQUEST_DETAILS_DAILY_AT` | string `HH:MM` | `backup.request_details.daily_at` |
| `ONGOINGAI_BACKUP_REQUEST_DETAILS_TEMP_DIR` | string | `backup.request_details.temp_dir` |
| `ONGOINGAI_BACKUP_REQUEST_DETAILS_PAGE_SIZE` | int | `backup.request_details.page_size` |
| `ONGOINGAI_BACKUP_REQUEST_DETAILS_SHARD_MAX_BYTES` | int64 | `backup.request_details.shard_max_bytes` |
| `ONGOINGAI_BACKUP_REQUEST_DETAILS_RETRY_MAX_ATTEMPTS` | int | `backup.request_details.retry.max_attempts` |
| `ONGOINGAI_BACKUP_REQUEST_DETAILS_RETRY_INITIAL_BACKOFF_MS` | int | `backup.request_details.retry.initial_backoff_ms` |
| `ONGOINGAI_BACKUP_REQUEST_DETAILS_RETRY_MAX_BACKOFF_MS` | int | `backup.request_details.retry.max_backoff_ms` |
| `ONGOINGAI_BACKUP_REQUEST_DETAILS_S3_BUCKET` | string | `backup.request_details.s3.bucket` |
| `ONGOINGAI_BACKUP_REQUEST_DETAILS_S3_PREFIX` | string | `backup.request_details.s3.prefix` |
| `ONGOINGAI_BACKUP_REQUEST_DETAILS_S3_REGION` | string | `backup.request_details.s3.region` |
| `ONGOINGAI_BACKUP_REQUEST_DETAILS_S3_ENDPOINT` | string | `backup.request_details.s3.endpoint` |
| `ONGOINGAI_BACKUP_REQUEST_DETAILS_S3_FORCE_PATH_STYLE` | bool | `backup.request_details.s3.force_path_style` |

`providers.*.prefix` does not currently have an environment override; set it in YAML.

## Validation

- Integer values must parse as base-10 integers.
- Boolean values must parse with Go `strconv.ParseBool`.
- Retention and backup times must use `HH:MM`.
- Timezones must be valid IANA timezone names when the related scheduler is enabled.
- `storage.driver` must be `sqlite` or `postgres`.
- `providers.llm.upstream` and backup S3 endpoints must include scheme and host.

## Examples

```bash
ONGOINGAI_PORT=9090 ongoingai config validate --config ongoingai.yaml
ONGOINGAI_PORT=9090 ongoingai serve --config ongoingai.yaml
```

```bash
ONGOINGAI_STORAGE_DRIVER=postgres \
ONGOINGAI_STORAGE_DSN=postgres://user:pass@db:5432/ongoingai?sslmode=require \
ongoingai serve --config ongoingai.yaml
```
