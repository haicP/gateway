Use this page to run OngoingAI Gateway from the command line.

## Commands

```bash
ongoingai serve [--config PATH]
ongoingai version
ongoingai --version
ongoingai -v
ongoingai config validate [--config PATH]
ongoingai shell-init [--config PATH]
ongoingai wrap [--config PATH] -- <command> [args...]
```

By default, commands read config from `ongoingai.yaml`. If the file is missing,
defaults and supported environment overrides are used.

## `ongoingai serve`

Starts the HTTP gateway with configured provider proxy routes, request detail
recording, optional request-detail backup, and optional trace retention cleanup.

```bash
ongoingai serve --config ongoingai.yaml
```

Exit codes:

| Code | Meaning |
| --- | --- |
| `0` | Clean shutdown |
| `1` | Startup or runtime failure |
| `2` | Flag parse error |

## `ongoingai version`

Prints the gateway version string.

```bash
ongoingai version
ongoingai --version
ongoingai -v
```

## `ongoingai config validate`

Loads and validates config without starting the server.

```bash
ongoingai config validate --config ongoingai.yaml
```

## `ongoingai shell-init`

Prints shell exports for provider SDK base URLs.

```bash
eval "$(ongoingai shell-init)"
```

## `ongoingai wrap`

Runs a command with gateway base URL environment variables injected.

```bash
ongoingai wrap -- python app.py
```

The wrapped command inherits stdin/stdout/stderr and exits with the child
process exit code.
